# 2026-04-20 平台 / 集团 / 门店三维变更说明

## 变更概述

本次调整围绕 `平台 / 集团 / 门店` 三维边界重新收口，统一了用户、角色、菜单权限和基础档案的归属关系。

## 模板与真实数据

- 模板数据：平台内置的角色、单位、物品类别、统计类型、物品标签，作为创建集团或门店时的初始化来源。
- 真实数据：集团或门店在各自作用域下实际维护的数据实例，和模板源分离。

## 主要变化

- 用户管理
  - 平台可见全量用户。
  - 集团仅可见自己集团下的用户。
  - 门店不再作为用户管理主体。
  - 手机号作为全局唯一标识。

- 角色管理
  - 平台只看到平台角色，不再看到任何集团角色。
  - 平台新增的角色都属于平台模板数据，可以编辑和删除。
  - 集团可以创建模板角色之外的自定义角色。
  - 门店没有角色管理页面和 API，门店角色由集团统一分配到用户。
  - `PLATFORM_SUPER_ADMIN` 保留为平台级兜底访问角色。

- 菜单权限
  - `GROUP` 角色不再看到平台菜单。
  - `PLATFORM` 角色仅看到平台管理菜单，不再看到物品管理菜单。
  - `GROUP` 角色继续看到集团菜单和基础模板菜单。
  - `STORE` 角色仅看到门店菜单。

- 基础档案
  - `物品管理`
  - `物品类别管理`
  - `单位管理`
  - `统计类型管理`
  - `物品标签管理`

  上述页面统一支持：
  - 模板数据作为新建集团/门店的复制源
  - 门店真实数据维护
  - 平台模板侧保留业务默认单位数据，例如 `件`、`箱`、`袋`、`个`、`瓶`、`盒`、`份`、`盘`、`碗`、`片`、`颗`
  - 平台不再以默认菜单形式直接看到物品管理页面

## 说明

- 本次变更仅包含代码与仓库内 release 记录。
- 未新增测试计划说明。
