# 2026-04-20 平台 / 集团 / 门店三维变更说明

## 变更概述

本次调整围绕 `平台 / 集团 / 门店` 三维边界重新收口，统一了用户、角色、菜单权限和基础档案的归属关系。

## 主要变化

- 用户管理
  - 平台可见全量用户。
  - 集团仅可见自己集团下的用户。
  - 门店不再作为用户管理主体。
  - 手机号作为全局唯一标识。

- 角色管理
  - 集团可以创建模板角色之外的自定义角色。
  - 门店没有角色管理页面和 API。
  - 门店角色由集团统一分配到用户。
  - `PLATFORM_SUPER_ADMIN` 保留为平台级兜底访问角色。

- 菜单权限
  - `GROUP` 角色不再看到平台菜单。
  - `PLATFORM` / `GROUP` 可编辑角色采用最小授权，不再默认全量菜单。
  - 物品基础档案相关菜单补齐到平台模板与集团菜单的可见范围中。

- 基础档案
  - `物品管理`
  - `物品类别管理`
  - `单位管理`
  - `统计类型管理`
  - `物品标签管理`

  上述页面统一支持：
  - 平台模板数据维护
  - 门店数据维护
  - 不再把集团作为这类数据的落库维度

## 说明

- 本次变更仅包含代码与仓库内 release 记录。
- 未新增测试计划说明。
