# 版本号：V2026.04.20.01

| 模块 | 详细内容 |
| --- | --- |
| 1. 新增功能 | 1. 角色模板属性：后端为 `sys_role` 新增 `builtin` 字段，支持区分平台模板角色与真实角色；2. 角色维护能力升级：角色新增/编辑接口支持传入 `builtin`，平台可维护模板角色和平台真实角色，集团仅允许维护真实角色；3. 单位分页能力：单位管理接口支持分页参数与分页结果，前端分页区改为使用真实分页数据。 |
| 2. 功能优化 | 1. 菜单授权边界收口：平台角色仅保留平台管理菜单和基础模板菜单，集团角色仅保留集团菜单，门店角色仅保留门店业务菜单；2. 门店管理页联动优化：前端不再额外拉取集团下拉，直接根据当前机构树推导集团上下文；3. 平台/集团权限判定优化：集团可管理范围改为按当前账号实际集团作用域判断，不再硬编码依赖单一 `GROUP_ADMIN` 角色。 |
| 3. BUG修复 | 1. 修复平台角色菜单越界问题：清理平台角色对物品管理页的错误授权，避免平台账号看到不该出现的真实业务页；2. 修复角色模板识别不稳定问题：角色模板判定从描述字段切换为显式 `builtin` 字段，避免模板角色被误识别；3. 修复单位管理前端伪分页问题：前端不再对当前页数据二次切片，避免总数与列表展示不一致；4. 修复门店管理集团切换异常：当当前上下文无法解析集团时，页面会清空旧数据，避免误展示历史门店列表。 |
| 4. 接口变更 | 1. `POST /api/identity/admin/roles`、`PUT /api/identity/admin/roles/{id}`：请求体新增 `builtin` 字段，用于声明角色是否为模板角色；2. `GET /api/identity/admin/units`：查询参数新增 `pageNum/pageSize`，返回值由纯数组调整为分页对象 `list/total/pageNum/pageSize`；3. 初始化脚本 `init.sql`、`seed-core.sql`：新增 `sys_role.builtin` 字段初始化与历史数据修正逻辑，并调整平台/集团/门店默认角色菜单装配规则。 |
