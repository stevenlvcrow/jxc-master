# 餐饮进销存系统（入库/出库/盘点）需求文档\+流程图\+数据库设计

# 一、餐饮进销存系统需求文档（核心版）

## 1\.1 文档概述

本文档针对餐饮行业进销存系统，聚焦入库、出库、盘点三大核心业务线，明确系统功能需求、业务流程、操作规范及约束条件，适配餐饮行业食材保质期短、损耗高、多单位换算、多场景领用的核心特点，为系统开发、测试及落地提供依据。

适用场景：单门店/多门店餐饮（中餐、西餐、快餐、奶茶店等），覆盖食材、调料、酒水、一次性耗材等全品类库存管理，核心解决“货、单、账、损耗”统一问题。

## 1\.2 核心业务目标

- 实现入库、出库、盘点全流程线上化，替代手工记账，减少人为误差；

- 精准管控食材库存，避免缺货、积压、过期，降低损耗成本；

- 实现库存数据实时同步，支撑后厨领料、成本核算、供应商对账；

- 适配餐饮多单位换算、多频次盘点需求，确保账实一致；

- 留存业务流水，支持数据追溯（入库记录、领用记录、损耗记录）。

## 1\.3 核心业务需求（入库/出库/盘点）

### 1\.3\.1 入库业务需求

#### 1\.3\.1\.1 采购入库（核心功能）

- 支持手动录入/导入采购入库单，字段包含：入库单号、供应商名称、到货日期、食材名称、规格、单位（箱/斤/克等）、数量、单价、金额、验收人、库管人；

- 支持食材验收环节，可录入验收数量（与送货数量不一致时，按实际验收数量入库），标注验收异常（如食材变质、规格不符）；

- 关联供应商信息，自动生成应付账款记录，支持后续对账、结款；

- 支持食材保质期录入，系统自动标记临期食材（如到期前3天提醒）；

- 入库完成后，自动更新对应食材库存数量及库存成本。

#### 1\.3\.1\.2 其他入库

- 支持赠品入库：录入赠品名称、规格、数量，无单价、无应付账款，仅更新库存；

- 支持调拨入库：多门店/多仓库调货时，接收方确认后，自动完成入库，更新库存；

- 支持盘盈入库：盘点后实盘数量大于账面数量时，自动生成盘盈入库单，调整库存。

#### 1\.3\.1\.3 入库记录管理

- 支持按入库日期、供应商、食材名称、入库类型查询入库记录；

- 支持入库单修改、删除（仅未审核状态可操作）；

- 支持入库单打印、导出（Excel格式）。

### 1\.3\.2 出库业务需求

#### 1\.3\.2\.1 后厨领用出库（核心功能）

- 支持厨师长/后厨人员提交领料单，字段包含：领料单号、领料日期、领料部门（后厨/凉菜间等）、食材名称、规格、单位、领用数量、领用用途、领用人、审核人；

- 支持领料单审核流程（库管人审核），审核通过后，自动扣减对应食材库存；

- 领用数量不得超过当前库存数量，系统自动校验，禁止超库存领用；

- 领用记录自动关联成本核算，领用食材金额计入当日后厨成本；

- 支持批量领料、重复领料（常用食材快速调用）。

#### 1\.3\.2\.2 销售出库（酒水/饮料）

- 支持前台点单后，自动生成销售出库单，扣减对应酒水、饮料库存；

- 关联销售订单，自动记录销售金额、销售数量，支撑毛利计算；

- 支持手动补录销售出库（如前台漏单情况），需审核后生效。

#### 1\.3\.2\.3 报损出库（高频功能）

- 支持录入报损单，字段包含：报损单号、报损日期、食材名称、规格、单位、报损数量、报损原因（变质、损耗、烹饪失误等）、上报人、审核人；

- 支持报损原因分类选择，便于后续损耗统计分析；

- 报损单审核通过后，自动扣减库存，报损金额计入损耗成本；

- 支持批量报损，标注报损食材是否已处理（如丢弃、销毁）。

#### 1\.3\.2\.4 调拨出库

- 支持多门店/多仓库调货，提交调拨出库单，字段包含：调拨单号、调出仓库、调入仓库、食材名称、规格、数量、调拨人、审核人；

- 调拨出库后，调出仓库库存减少，调入仓库待确认入库；

- 支持调拨记录查询，跟踪调拨进度。

#### 1\.3\.2\.5 出库记录管理

- 支持按出库日期、出库类型、食材名称、领用部门查询出库记录；

- 支持出库单修改、删除（仅未审核状态可操作）；

- 支持出库单打印、导出，便于成本核对。

### 1\.3\.3 盘点业务需求

#### 1\.3\.3\.1 盘点准备

- 支持选择盘点范围（全仓盘点、分区盘点、指定食材盘点）；

- 支持冻结库存（可选），盘点期间禁止出入库操作，确保盘点准确性；

- 支持导出账面库存清单（包含食材名称、规格、单位、账面数量、库存成本），便于现场核对。

#### 1\.3\.3\.2 现场盘点

- 支持手动录入实盘数量，或扫码录入（适配食材条码/二维码）；

- 支持按品类、库区分组盘点，多人协同盘点（分工录入）；

- 支持盘点过程中保存草稿，可多次修改实盘数量；

- 支持标注盘点异常（如食材串码、过期、丢失）。

#### 1\.3\.3\.3 差异处理

- 系统自动计算差异数量（实盘数量\-账面数量）、差异金额，生成盘点差异表；

- 支持录入差异原因（自然损耗、加工损耗、录入错误、丢失等）；

- 支持差异审核，审核通过后，自动生成盘盈入库单/报损出库单，调整库存至实盘数量；

- 支持差异记录留存，便于后续追溯、分析损耗原因。

#### 1\.3\.3\.4 盘点记录管理

- 支持按盘点日期、盘点范围、盘点人查询盘点记录；

- 支持盘点单、差异表打印、导出；

- 支持盘点历史对比，查看不同时期盘点数据，分析库存波动。

## 1\.4 非功能需求

- 易用性：操作界面简洁，适配餐饮工作人员（库管、后厨、前台），无需专业培训即可上手；

- 实时性：库存数据、业务流水实时更新，延迟不超过10秒；

- 安全性：支持权限管控（库管仅操作出入库、盘点，管理员可查看报表、修改权限），操作记录可追溯；

- 兼容性：支持电脑端、平板端操作（适配后厨、仓库移动录入）；

- 可扩展性：支持多门店扩展、食材品类新增、报表自定义。

## 1\.5 约束条件

- 食材库存不可为负，超库存领用、报损时，系统自动拦截；

- 已审核的出入库单、盘点单，不可直接删除，仅可作废并留存记录；

- 保质期到期的食材，系统自动提醒，禁止领用、销售，仅可报损出库；

- 多单位换算需提前设置（如1箱=12瓶、1斤=500克），系统自动换算，不可手动修改换算比例。

# 二、餐饮进销存系统核心流程图

## 2\.1 整体业务流程图

```mermaid

flowchart TD
    A[供应商送货/客户退货/赠品] --> B[入库业务]
    B --> C[库存管理（实时更新）]
    C --> D[出库业务（领用/销售/报损/调拨）]
    C --> E[盘点业务]
    D --> C
    E --> F[差异处理（盘盈/盘亏）]
    F --> C
    C --> G[成本核算/对账/报表]
    ```

## 2\.2 入库业务流程图

```mermaid

flowchart TD
    A[供应商送货/赠品到店] --> B[库管/后厨验收]
    B -->|验收合格| C[录入入库单（食材信息、数量、单价）]
    B -->|验收不合格| D[退回供应商/拒收]
    C --> E[审核入库单]
    E -->|审核通过| F[更新库存（增加）+ 生成应付账款（采购入库）]
    E -->|审核不通过| G[修改入库单/作废]
    F --> H[入库记录留存，可查询/导出]
    ```

## 2\.3 出库业务流程图

```mermaid

flowchart TD
    A[出库发起] -->|后厨领用| B[提交领料单（食材、数量、用途）]
    A -->|酒水销售| C[前台点单，自动生成销售出库单]
    A -->|食材报损| D[提交报损单（食材、数量、原因）]
    A -->|调拨| E[提交调拨出库单（调出/调入仓库、食材）]
    
    B --> F[库管审核]
    C --> F
    D --> F
    E --> F
    
    F -->|审核通过| G[扣减对应库存]
    F -->|审核不通过| H[修改单据/作废]
    
    G -->|领用| I[计入后厨成本，留存领用记录]
    G -->|销售| J[关联营收，计算毛利，留存销售记录]
    G -->|报损| K[计入损耗成本，留存报损记录]
    G -->|调拨| L[调出仓库库存减少，等待调入方入库]
    ```

## 2\.4 盘点业务流程图

```mermaid

flowchart TD
    A[发起盘点] --> B[选择盘点范围（全仓/分区/指定食材）]
    B --> C[冻结库存（可选）+ 导出账面库存清单]
    C --> D[现场盘点，录入实盘数量]
    D --> E[系统自动计算差异（实盘-账面）]
    E --> F[录入差异原因，提交审核]
    F --> G[负责人审核]
    G -->|审核通过| H[生成盘盈入库单/报损出库单]
    G -->|审核不通过| I[重新录入实盘数量/修改差异原因]
    H --> J[调整库存，使账面=实盘]
    J --> K[留存盘点记录、差异表，可查询/导出]
    ```
